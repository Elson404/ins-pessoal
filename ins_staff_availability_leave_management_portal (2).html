Como Hospedar esta Plataforma Gratuitamente

Passos simples para disponibilizar esta aplicação online para os membros da secretaria testarem.

1 Netlify Drop (Mais Fácil)

1. Aceda a app.netlify.com/drop.
2. Arraste o ficheiro index.html para a área assinalada.
3. Obterá um link público instantâneo (ex: https://ins-pessoal.netlify.app).

2 GitHub Pages

1. Crie um repositório no GitHub chamado ins-pessoal.
2. Faça upload do ficheiro index.html.
3. Nas definições do repositório, ative o "Pages" no ramo main.

3 Vercel

1. Aceda a vercel.com.
2. Importe o seu projeto HTML.
3. Publicação em segundos com certificado SSL/HTTPS seguro gratuito.

Nota sobre Dados: Toda a informação (funcionários, missões) é guardada em memória local (LocalStorage) no navegador do utilizador de forma rápida e segura sem necessidade de servidor de base de dados.
